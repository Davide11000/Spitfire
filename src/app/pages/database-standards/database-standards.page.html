DATABASE STANDARDS

Requests

Cite reliable sources

Provide reliable sources from well known and established websites (e.g. Wikipedia, Last.fm, Bandcamp) or from verified quotes by the artists themselves. Always cite your sources in the Source field of the request.

Keep it relevant

Please avoid inserting superfluous information in your request. Stick strictly to information relevant to the artist's career, influences and artistic choices.

Incomplete artist requests

Incomplete artist requests can be accepted in case the available information about them is scarce or unverifiable, but at least 1 record must be provided to justify the artist's inclusion in the database.

Prefer records over artists

Unless strictly necessary, it is preferable to submit a request for a record from a new artist rather than one for the artist themselves, as a page for them will be automatically created.

Lyrics

Lyrics should be a faithful transcription of what is actually sung, so that everyone can read, annotate and translate them in the same way.

Transcribe exactly what is sung

Write the words as they are performed, not as they appear in other versions. Use standard spelling, unless the artist clearly pronounces a word in an unusual way on purpose (e.g. gonna, 'cause). If you can't understand a word, write [?] instead of guessing.

Use section headers

Divide the song into sections, with a header in square brackets on its own line and an empty line between sections:

[Intro]
[Verse 1]
[Pre-Chorus]
[Chorus]
[Bridge]
[Outro]

If more artists perform, add who sings each part: [Verse 2: Artist name].

One line per sung line

Every line of the lyrics should match a line as it is sung. Start each line with a capital letter and don't end it with a comma or a full stop; question and exclamation marks are fine.

Write out repetitions

Don't use shortcuts like "x2" or "(Repeat chorus)": write every line every time it is sung, so that each part can be annotated.

Background vocals and ad-libs

Put background vocals and ad-libs in round brackets, on the same line as the main vocals:

I've been waiting all night (All night)

Nothing that isn't sung

Don't add credits, timestamps, descriptions or comments inside the lyrics. Information about the song goes in the other fields, and explanations go in the annotations.

Original language only

Lyrics must be in the language they are sung in, without censoring or changing words. Translations are added separately, with Translations → Add a translation on the song page.

Annotations

Explain, don't repeat

An annotation should add something the lyrics don't say: the meaning of a line, a reference, a story behind it. Don't simply rewrite the line with other words.

Back it up

When you write about facts (interviews, events, samples), mention where they come from. Personal interpretations are welcome, as long as they are presented as such.

Improve, don't duplicate

If a part of the lyrics already has an annotation, use Edit or Suggest an improvement instead of writing a new one.
